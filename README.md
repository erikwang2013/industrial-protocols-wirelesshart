# WirelessHART 协议包 — 需 Emerson 1410/1420 Smart Wireless Gateway 桥接

> [English](README.en.md)

WirelessHART (IEC 62591) 工业无线 HART 协议（IEEE 802.15.4）。需要 Emerson 1410/1420 Smart Wireless Gateway，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-wirelesshart
```

## 功能

WirelessHART 无线网络桥接、BridgeConnector 连接管理

## 所需硬件

Emerson 1410 Smart Wireless Gateway、1420 Wireless Gateway

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Plain PHP

## 系统要求

- PHP >= 8.1
- WirelessHART 网关
- erikwang2013/industrial-protocols-kernel
